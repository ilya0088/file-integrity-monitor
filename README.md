# 🔒 File Integrity Monitor (FIM)

Лёгкий инструмент на Python для отслеживания несанкционированных изменений файлов с помощью SHA-256 хеширования. Полезен для мониторинга конфигурационных файлов, веб-директорий или любых критичных данных на предмет неожиданных изменений.

![Python](https://img.shields.io/badge/python-3.8+-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

## 📋 Возможности

- Создание baseline (эталонного снимка) директории
- Обнаружение новых, удалённых и изменённых файлов
- Хеширование по SHA-256 (устойчиво к коллизиям)
- Режим непрерывного мониторинга (`watch`) с заданным интервалом
- Без сторонних зависимостей — только стандартная библиотека Python

## 🖥 Демо

```
$ python file_integrity_monitor.py check test_dir

  Новые файлы:
    + test_dir/c.txt

  Удалённые файлы:
    - test_dir/b.txt

  Изменённые файлы:
    * test_dir/a.txt
```

## ⚙️ Установка

```bash
git clone https://github.com/ilya0088/file-integrity-monitor.git
cd file-integrity-monitor
```

Зависимостей нет — только Python 3.8+.

## 🚀 Использование

**1. Создать baseline (эталон) для директории:**
```bash
python file_integrity_monitor.py init /path/to/directory
```

**2. Проверить изменения относительно baseline:**
```bash
python file_integrity_monitor.py check /path/to/directory
```

**3. Непрерывный мониторинг (проверка каждые N секунд):**
```bash
python file_integrity_monitor.py watch /path/to/directory 30
```

## 🧠 Как это работает

1. При инициализации скрипт рекурсивно сканирует директорию и вычисляет SHA-256 хеш каждого файла
2. Результат сохраняется в `.fim_baseline.json` внутри отслеживаемой директории
3. При проверке текущее состояние файлов сравнивается с baseline
4. Любое расхождение хешей, появление новых или исчезновение файлов фиксируется в отчёте

Это базовый принцип, лежащий в основе промышленных HIDS-решений (Host-based Intrusion Detection Systems) вроде Tripwire или OSSEC.
